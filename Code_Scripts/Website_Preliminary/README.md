# Code for Website(Version 1)

## How to use?

- Create a new folder;

- According to the following setup, download the python files in Github and apply them:

  /New folder created
    /app.py (file in Github)
    /models (folder)
      /best.pt
    /results (empty folder)
    /uploads (empty folder)
    /templates
      /index.html
    /utils
      /analysis.py

- Modify the path in file "app.py" to suit your own computer

- Run the file "app.py", it will produce an API as output("pip" all the packages required before running)

- Open the API, it will be the website.
