# Annotating by Makesense Website

## 1.打开makesense网站，点击右下角Get started

## 2.点击click here to choose file

## 3.选择完毕后，手动输入添加标签

$\bullet$ 混沌摆实验标签有两个，分别为中心点central_point和关键点key_point

## 4.使用矩形模式(rect)**按顺序**框选中心点和关键点

$\bullet$ 中心点在前，关键点在后，每一张图片务必确认！

## 5.所有图片完成标注后，点击左上角Actions

## 6.选择操作export，并选择文件类型为第一个选项YOLO文件

## 7.在指定的路径得到一个压缩包即完成，可直接发送分享压缩包
